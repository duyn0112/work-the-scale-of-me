# work-the scale of me

作者：**duyn0112**。

源码仓库：[duyn0112/work-the-scale-of-me](https://github.com/duyn0112/work-the-scale-of-me)。

**work-the scale of me** 是一个可以连续缩放的交互网页，页面展示名称为“宇宙的尺度 · 我的版本 / The Scale of Me”。以 1.77 米的身高标尺为参照，把 DNA、细胞、日常物品、建筑、城市、政区地图以及地球、月球放进同一个以米计量的场景，直观比较不同事物的大小。

主页面使用原生 HTML、CSS 和 JavaScript 编写，样式、脚本和场景图片均内嵌在 `index.html` 中。无需安装依赖、编译或配置 API 密钥，也不需要数据库和后端服务。

## 功能

- 连续缩放和平移：当前代码支持约 7 纳米至 80,000 公里的视野高度，左下角显示当前视野高度与米制数量级。
- 对象定位：点击物品或右侧尺度刻度，平滑移动到对应对象，查看简介和尺寸。
- 多种尺度内容：当前默认清单包含 77 个对象，覆盖微观生物、科技、日常物品、建筑、地理和天体。
- 自定义清单：编辑对象名称、尺寸、单位和注解；添加自定义对象，并删除自己添加的对象。自定义对象使用通用图形展示，暂不支持上传图片。
- 本地保存：清单修改保存在当前浏览器的 `localStorage` 中，可通过“恢复默认”重置。
- 参考图查看：在辽河详情中查看水系原始参考图。

## 运行

建议使用较新版本的 Chrome 或 Edge 桌面浏览器，搭配鼠标或触控板。页面使用 Pointer Events、`<dialog>`、`inert` 和现代 CSS；尚未建立完整的跨浏览器兼容性测试记录。

### 直接打开

下载或克隆仓库后，用浏览器打开根目录的 `index.html`。主页面自带场景素材，可离线展示。

### 本地静态服务器（推荐）

如果电脑已安装 Python 3，在项目根目录运行：

```bash
python -m http.server 8000 --bind 127.0.0.1
```

然后访问 <http://127.0.0.1:8000/>。结束时在终端按 `Ctrl+C`。如果系统使用 `py` 启动 Python，可将命令中的 `python` 换为 `py`。

静态服务器有助于统一浏览器存储和资源访问行为。直接打开文件时，`file://` 页面的本地存储行为可能因浏览器而异。Python 只用于可选的本地预览，不是网页的运行依赖。

## 使用方法

| 操作 | 效果 |
| --- | --- |
| 滚动鼠标滚轮或触控板 | 放大或缩小视野 |
| 按住鼠标左键拖动场景 | 平移视野 |
| 点击物品或右侧刻度 | 定位对象并显示详情 |
| 双击场景，或点击“回到中心” | 返回中心位置，保留当前缩放级别 |
| 点击“我的尺度清单”，或按 `E` | 打开清单；`E` 也可关闭清单（输入文字时不触发） |
| 在清单中修改数值、名称或注解 | 输入变更提交后更新场景，并尝试保存到本地 |
| 在清单下方填写名称、正数尺寸和单位，再点击“添加” | 添加一个自定义对象 |
| 点击自定义对象右侧的 `×` | 删除该自定义对象；内置对象没有删除按钮 |
| 按 `Esc` | 关闭原图弹窗、清单或当前对象详情 |
| 点击“恢复默认” | 清除所有自定义对象与内置对象的编辑值 |

支持纳米、微米、毫米、厘米、米和公里。恢复默认会直接执行，请先自行记录需要保留的修改。

浏览器存储键为 `scale-of-me.v1`。数据不会自动上传或跨设备同步；更换浏览器、域名或端口、清理站点数据，都可能使原有修改不可用。浏览器禁止存储时，页面仍可运行，但修改可能无法保留。当前没有内置的数据导出、导入和撤销功能。

## 尺度的含义与限制

这里比较的是对象采用的尺寸基准。场景内的摆放位置用于展示，不表示对象的真实地理位置、空间距离或地月距离。

- 生物、物品和建筑使用典型值、选定型号、参考照片标定值或明确的示意假设，并非所有个体的统一尺寸。
- “3 nm 芯片”表示工艺节点的名义尺度，不表示整颗芯片的物理边长；其他结构图也含示意简化。
- 政区地图采用公开边界推算的地理包围范围。投影、岛屿和插图布局会影响比例；美国连续 48 州、阿拉斯加和夏威夷不应按同一幅平面比例解释。
- 路线里程与图形宽高含义不同。沈海高速约 3,710 公里和辽河约 1,345 公里采用各自的路线或河流长度口径，不能直接视作整幅图的高度。

数据口径详见 [物品尺寸](sticker-objects-scale.md)、[重绘尺寸](redraw-scale.md)、[地月尺寸](earth-moon-scale.md) 和 [政区图尺寸](政区图尺寸数据.md)。历史文档的旧运行参数不一定与当前代码一致，运行行为以 `index.html` 为准。本项目适合学习和直观比较，不用于工程测量或精密地理分析。

## 修改与维护

主页面中的主要数据与逻辑位于以下位置：

| 标识 | 用途 |
| --- | --- |
| `BASE` | 默认对象清单；`s`、`body` 和 `art` 的长度均以米计 |
| `ASSETS` | 以文件名为键的内嵌 Data URL 素材表 |
| `VIEW_MIN` / `VIEW_MAX` | 视野高度的上下限 |
| `HOME` | 初始相机位置与视野 |
| `KEY` | 浏览器存储键 |
| `layout` / `render` | 场景排列与显示 |

`assets/` 中的独立文件与 `ASSETS` 是两份资源副本。目前没有自动同步或构建脚本，修改独立素材不会自动改变主页面；更新时应同时检查预览页、主页面内嵌资源及署名记录。
